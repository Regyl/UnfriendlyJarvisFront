# Иконки сервисов

Эта папка содержит SVG иконки для различных сервисов.

## Автоматическая загрузка

Иконки автоматически загружаются с Icons8 CDN, если локальные файлы отсутствуют.

## Ручная загрузка

Чтобы использовать локальные SVG файлы:

1. Перейдите на https://icons8.com/icons/
2. Найдите и скачайте SVG иконки для:
   - `soundcloud.svg`
   - `steam.svg`
   - `yandex-music.svg` (или `yandex_music.svg`)
   - `telegram.svg`
   - `fitbit.svg`
   - `strava.svg`
   - `tinkoff.svg`
   - `sber.svg`
3. Сохраните файлы в эту папку (`public/icons/`)

Компонент `ProviderIcon` автоматически будет использовать локальные файлы, если они существуют, иначе будет использовать CDN.
