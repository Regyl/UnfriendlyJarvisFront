# Настройка иконок сервисов из Icons8

Этот проект использует иконки с сайта [Icons8](https://icons8.com/icons/).

## Автоматическая загрузка (рекомендуется)

Иконки автоматически загружаются с CDN Icons8, если локальные файлы отсутствуют.

## Ручная загрузка (для офлайн-режима)

Чтобы использовать локальные иконки:

1. Перейдите на [Icons8.com](https://icons8.com/icons/)
2. Скачайте SVG иконки для следующих сервисов:
   - SoundCloud
   - Steam
   - Яндекс.Музыка (Yandex Music)
   - Telegram
   - Fitbit
   - Strava
   - Tinkoff
   - Sber (Сбербанк)

3. Сохраните SVG файлы в папку `public/icons/` со следующими именами:
   - `soundcloud.svg`
   - `steam.svg`
   - `yandex-music.svg`
   - `telegram.svg`
   - `fitbit.svg`
   - `strava.svg`
   - `tinkoff.svg`
   - `sber.svg`

4. Компонент автоматически будет использовать локальные файлы вместо CDN.

## Прямые ссылки для скачивания

Вы можете использовать следующие ссылки для быстрого поиска иконок:

- [SoundCloud](https://icons8.com/icons/set/soundcloud)
- [Steam](https://icons8.com/icons/set/steam)
- [Telegram](https://icons8.com/icons/set/telegram)
- [Fitbit](https://icons8.com/icons/set/fitbit)
- [Strava](https://icons8.com/icons/set/strava)

Для российских сервисов (Яндекс.Музыка, Tinkoff, Sber) используйте поиск на сайте Icons8.
